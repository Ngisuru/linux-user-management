# Linux User & Permission Management System

A Bash-based Linux administration tool for managing users, groups, permissions, shared directories, activity logs, and configuration backups.

## Features

- Create Linux users
- Delete Linux users
- Create groups
- Add users to groups
- Remove users from groups
- Create group-based shared directories
- Configure directory permissions
- Use Setgid for shared directories
- View users and groups
- View group members
- Maintain activity logs
- Backup Linux user and group configuration

## Technologies Used

- Linux / Ubuntu
- Bash Scripting
- Linux Users & Groups
- File Permissions
- `chmod`
- `chown`
- `usermod`
- `useradd`
- `userdel`
- Git & GitHub
